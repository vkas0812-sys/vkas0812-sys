Veterinarian using **nutrition analysis**, **operations data**, and the **One Health** lens to improve animal health and production decisions.

I combine clinical training with formulation work and analytics: cost vs. nutrient trade-offs, inventory and output tracking, disease-aware production thinking, and market-facing research.
